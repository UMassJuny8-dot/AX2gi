# 🚢 무역직무 MBTI 테스트 (Trade Career MBTI Test)

무역마스터 부트캠프 프로젝트의 일환으로 제작된 웹 애플리케이션입니다. 
개인의 성향을 20가지 질문을 통해 분석하여, 6가지 주요 무역 직무 중 가장 적합한 롤(Role)을 추천해 줍니다.

## 📌 주요 기능 (Features)
- 20개의 무역/오피스 환경 기반 상황별 질문 제공
- E/I, S/N, T/F, J/P 응답을 합산하여 16가지 MBTI 도출
- 도출된 MBTI를 기반으로 6가지 주요 무역 직무 매칭
  1. 해외영업 (Overseas Sales)
  2. 무역사무 및 서류 (Trade Documentation)
  3. 물류/SCM 관리 (Logistics/SCM)
  4. 해외마케팅 (Overseas Marketing)
  5. 무역 규제 및 통관 (Customs/Compliance)
  6. 소싱 및 구매 (Sourcing/Purchasing)

## 🛠️ 기술 스택 (Tech Stack)
- **Language**: Python 3
- **Framework**: Streamlit
